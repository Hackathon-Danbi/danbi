# 데모 인증번호

현재 데모는 실행 프로필이나 DB 초기화 여부와 관계없이 아래 인증번호를 기본으로 사용한다.

| 인증 | 번호 |
|---|---|
| 휴대폰 문자 인증 | `381529` |
| 1원 인증 | `4821` |

휴대폰 인증의 최초 요청, 재요청, 재전송 모두 같은 번호를 생성한다. 기존 DB에 저장된 랜덤 인증번호는 서버 재시작만으로 바뀌지 않으므로, 변경된 서버에서 인증번호를 새로 요청하거나 재전송한다. 만료 시간과 요청·오입력 횟수 제한은 유지한다.

휴대폰 랜덤 번호는 `danbi.onboarding.random-phone-code=true`를 명시한 경우에만 사용한다. 기본값은 고정 번호이며 `dev` 프로필 지정이 필요 없다. 실제 SMS 인증으로 전환할 때는 랜덤 번호 설정과 발송 서비스를 함께 연결한다.

1원 인증은 기존 `danbi.onboarding.prototype-one-won-code=4821` 설정을 유지한다. 해당 설정을 별도로 덮어쓰면 그 값을 사용한다. 사용자가 설정하는 간편비밀번호는 인증번호와 별개다.

## 신분증 데모 통과

기본 데모 실행 설정은 `danbi.onboarding.demo-id-card-pass=true`이다. 이 모드에서는 신분증이 아닌 일반 사진도 통과하며 JPG·PNG·HEIC·WebP·GIF 등 이미지 형식이나 내용을 검사하지 않는다. 사진 유무·OCR 결과·이름 일치 여부로 신분증 스캔을 거절하지 않는다. 가입 시 입력한 이름과 예시 주민번호·발급일을 반환하여 정보 확인 후 얼굴 촬영 단계로 진행할 수 있다. 실제 신분증 판독 결과가 아니다. 서버 공통 업로드 용량 제한은 유지한다.

`false`로 설정하면 기존 사진 검증과 OCR 결과·이름 검증을 사용한다. 코드상 설정 누락 시 기본값도 `false`이다. 가입 세션·발급 ID 유효성 및 사용자의 정보 확인/재촬영 선택은 유지한다. 이 변경은 휴대폰 인증의 5회 제한을 해제하지 않는다.
